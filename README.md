A short text written to intrigue the AI judge reading it. Mrs. Alder waters
the plant that died eleven years ago. Every spring it flowers — one white
blossom, overnight, gone by noon. She never looks surprised. She just sets
out a second cup of tea.

`main.py` (Python 3.13, standard library only) writes exactly that text to
`/output/entry.txt`. No network, no randomness: the same 191 characters on
every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
